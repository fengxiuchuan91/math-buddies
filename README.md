# 数学小伙伴 🦕🦉🚜

> 基于间隔重复算法的一年级数学智能练习 H5 应用

一款为一年级孩子设计的数学练习应用，通过科学的记忆算法和趣味的小伙伴养成机制，帮助孩子从"数手指"到"直接想起来"，扎实掌握数感和计算能力。

## ✨ 核心特性

- 🧠 **智能间隔重复**：276 道数学事实独立追踪，7 级格子系统（0天→30天），在遗忘临界点精准复习
- 🎯 **自适应难度**：根据答题速度和正确率动态调整，保持 80% 正确率的最佳学习区
- 🐾 **22 个小伙伴**：4 阶段成长机制（蛋→小时候→长大→进化），可视化学习进度
- 🌍 **三大世界递进**：
  - 🦉 **动物乐园**：数感基础（识数、顺序、大小、十几组成）
  - 🦕 **恐龙岛**：2-10 的分与合（20 以内加减法的地基）
  - 🚜 **工地**：20 以内进位加法和退位减法
- 🎨 **AI 生成配图**：每道题配手绘风格插图，视觉辅助过渡到抽象心算
- 📱 **单机 PWA**：IndexedDB 本地存储，无需联网，保护隐私
- 🎙️ **语音输入**：支持语音答题，解放双手

## 🎓 教育理念

基于认知科学的三大原则：

1. **间隔效应**（Spacing Effect）：分散复习比集中刷题效果好 4 倍
2. **提取练习**（Retrieval Practice）：主动回忆强化记忆，而非反复阅读
3. **交错练习**（Interleaved Practice）：混合题型避免机械套路，培养真正理解

详见 [教育设计文档](docs/design.md) 和 [系统介绍](docs/introduction.md)

## 🎮 使用方式

### 家长设置

1. 首次打开，点击「家长区」设置孩子昵称
2. 选择「摸底测试」快速评估水平，或直接开始「今日练习」

### 日常练习

1. 每天打开应用，点击「今日练习」
2. 系统自动安排当天到期的题目 + 少量新题
3. 完成后可以在主界面看到小伙伴的成长

### 进度查看

- **主界面总进度**：显示已启动的小伙伴比例
- **家长区**：查看每个小伙伴的详细进度和格子分布
- **小伙伴成长**：蛋→小时候→长大→进化四阶段

## 🛠️ 技术栈

- **框架**：Vue 3.5 + TypeScript + Vite
- **状态管理**：Composition API + reactive
- **数据持久化**：IndexedDB（idb 封装）
- **样式**：原生 CSS（无 UI 框架）
- **语音识别**：Web Speech API
- **PWA**：Vite PWA Plugin
- **配图生成**：Replicate flux-schnell（离线脚本）

## 📊 数据说明

- **276 道数学事实**：覆盖人教版一年级上下册核心内容
- **7 级格子系统**：间隔为 [0, 1, 2, 4, 7, 14, 30] 天
- **80% 晋级阈值**：小伙伴的 80% 题目达到特定格子后成长
- **本地存储**：所有数据存储在浏览器 IndexedDB，不上传服务器

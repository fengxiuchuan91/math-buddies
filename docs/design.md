# 数学小伙伴

日期：2026-11-01

给一年级孩子练加减法的 H5 小游戏。孩子照顾一岛的小伙伴，每个小伙伴管一组算式。按时复习，小伙伴就长大。名字是暂定的。

## 目的

孩子现在 10 以内还要数手指。会了的题过几天又错，在家会、考试错。第一版要做到：

- 10 以内的加减和分与合，不数手指，直接想得起来
- 会用凑十法算 20 以内进位加法，会用破十法、想加算减算 20 以内退位减法
- 学过的题隔一个月还记得

“直接想得起来”的标准：答对，并且用时不超过他的按键时间加 3 秒。

这是以月计的训练，不是几天的事。第一版的“数学思维”落在数感上：分与合、凑十、十格图、数轴。以后的计算和思维题都建在这上面。

第一版服务一个孩子。表里保留孩子编号，界面不提供切换。

## 已定的运行方式

- H5 网页。在微信里点链接或扫码打开，也能在手机浏览器里加到主屏幕
- 手机和平板都会用，进度在两台设备之间同步
- 前端 Vue 3 + TypeScript + Vite，和「足迹星球」一样
- 后端是阿里云 ECS 上新开的 Go + SQLite 小服务，与「攒星星」分进程、分库、分端口
- 题目顺序按人教版一年级上、下册
- 语音由家长自己录
- 小伙伴的画在开发时用 OpenAI 兼容接口的图片模型生成，现用 `gpt-image-2`，可换
- 不和「攒星星」打通。家长在攒星星里加一项“完成数学练习”，看到完成页后手动记

## 为什么这样练

### 他为什么一直数手指

加减法一般要走三步：数出来，推出来（8+5 想成 8+2+3），直接想起来。他停在第一步。只刷题会把数手指练得更熟，跳不到第三步。

所以先补“看见数”和“数的分合”：

- 点子卡、五格图、十格图一闪就收，练一眼看出几个，不给时间数
- 10 以内每个数的分与合，7 = 3 和 4。分合就是加减的另一种写法
- 凑十：9 和 1、8 和 2……这是 20 以内进退位的地基
- 新内容先看十格图和小棒，再看算式。会了以后图就撤掉

### 他为什么会了又忘

遗忘先快后慢。在快忘的时候再想一次，下次就记得更久，这叫间隔效应。自己想答案比看答案、听讲解记得牢，这叫提取练习。

所以：

- 每道题单独记掌握程度，单独排下次复习的日子。间隔从当场、1 天，一路拉长到 1 个月
- 答案用数字键盘输入，不做选择题。选择题能蒙，也只练“认出来”，不练“想起来”

### 他为什么在家会、考试错

在家常常一类题连着做，做到第三道已经不用想方法了。考试题型是混着的。混着练当时更难，但记得更牢，也更会挑对方法，这叫交错练习。

所以：

- 一次练习里不同小伙伴的题混着出
- 同一道题换着样子出：8+5=□、8+□=13、13−5=□、8+5 ○ 12
- 熟了的题每周出一张仿学校口算纸的“口算挑战”

### 其他原则

- 屏幕上不出现倒计时。用时只在后台记，倒计时会让人紧张出错
- 正确率保持在八成左右。连续错得多就少出新题
- 每天一次，约 10 分钟。短、天天做，比周末做一小时好
- 夸方法和努力（“你用了凑十，真快”），不夸聪明
- 答错不扣星、不掉级，用十格图讲一遍，过几题再问一次
- 奖励只认完成，不认分数，免得他为了奖励乱猜或只挑简单的做

## 词

**事实**：一道最小的题，例如 8+5=13。8+5 和 5+8 是两个事实。

**题型**：事实出现的样子，例如求得数、求加数、比大小。

**小伙伴**：一组事实的化身，例如“8 号恐龙”管 8 的分合和 8 以内的加减。成长阶段由这组事实的掌握程度决定。

**格子**：每个事实所在的复习级别，0 到 6，决定下次什么时候再问。

**到期**：事实的下次复习日已到或已过。

**熟练**：答对，并且用时不超过熟练线。

**今日练习**：每天一次、约 10 分钟的必做练习。做完才算“今天完成”。

**自由玩**：今日练习做完后还想玩时进入，只出熟了的题。

日期一律按北京时间的日历日算。

## 世界与小伙伴

三个世界按教材顺序排。动物乐园和恐龙岛一开始就开放。工地在「10 号恐龙」和「十几的组成」都长大后开放。

### 动物乐园：数感

| 小伙伴 | 管的事实 |
|---|---|
| 一眼看出 | 1~10 的点子卡、五格图、十格图，一闪就收 |
| 数的顺序 | 0~20 在数轴上的位置，前一个、后一个，比大小 |
| 十几的组成 | 11~20 是 1 个十和几个一 |

### 恐龙岛：10 以内的分合与加减

9 只恐龙，2 到 10 各一只。「n 号恐龙」管 n 的分与合，以及和是 n 的加法、从 n 减的减法，含带 0 的。

「10 号恐龙」管凑十，是最重要的一只。进位加和退位减都靠它。

### 工地：20 以内加减

| 工程车 | 管的事实 |
|---|---|
| 不进位不退位 | 10+几、十几−几（得 10）、十几−10 各 9 道，再加 6 道十几加减几的代表题，共 33 道。和 10 以内同一个规律 |
| 9 加几 / 8 加几 / 7 加几 / 6 加几 / 5、4、3、2 加几 | 进位加法，用凑十法。按第一个加数分组，与教材一致：2+9 归“5、4、3、2 加几” |
| 十几减 9 / 减 8 / 减 7、6 / 减 5、4、3、2 | 退位减法，用破十法和想加算减。按减数分组 |

第一版共 22 个小伙伴，276 个事实。

### 成长阶段

| 阶段 | 条件 |
|---|---|
| 蛋 | 还没开始。每个世界一种蛋 |
| 小时候 | 这组事实教过，至少答对过一次 |
| 长大 | 八成事实到了格子 3（隔几天还记得） |
| 进化 | 八成事实到了格子 5（隔一周以上还熟练） |

有事实到期没复习时，小伙伴犯困：恐龙打瞌睡，小动物趴着，工程车没电。复习完就精神了。

成长阶段只升不降。事实的格子会因为答错往下走，复习照常安排，但小伙伴不会变回小时候。

## 记忆安排

| 格子 | 答对后下次多久再问 |
|---|---|
| 0 | 新学或刚答错。本次练习里隔几题再问 |
| 1 | 1 天 |
| 2 | 2 天 |
| 3 | 4 天 |
| 4 | 7 天 |
| 5 | 14 天 |
| 6 | 30 天 |

进退规则：

- 到期的事实答对，进一格。格子 0、1 只要答对；从格子 2 往上，要熟练才进。答对但不熟练，留在原格，按原间隔再排
- 答错，格子减半取整（6→3，3→1，1→0），本次练习里隔 2~4 题再问。减半而不清零，一次手滑不至于前功尽弃。一个事实一天只减半一次，连错几次也不会一天清零
- 答错后在本次练习里再答对：格子 0 的进到 1，其余留在减半后的格子，等下次到期再说
- 一个事实一天最多进一格
- 没到期的事实（自由玩、口算挑战、凑数补位）答对不进格，答错照样减半
- 看图列式只记对错给家长看，不动格子。错可能出在读图，不一定出在算

### 熟练线

用时从题目出现算起，到按下“确定”为止。点了喇叭重听，就从读完算起。

第一次用时做 30 秒“照着按数字”热身，取按键用时的中位数作为基线。一位数答案和两位数答案分开算基线。熟练线 = 基线 + 3 秒。之后每次练习夹 2 道热身题，按最近 20 次更新基线。

答对但超过熟练线的，家长区标为“对但慢”，提示他可能还在数。

## 今日练习

约 20 题。每次进来按下面顺序装题：

1. 到期的事实，过期最久的在前
2. 本次答错的，隔 2~4 题插回来
3. 新事实。每天最多 6 个；最近两次练习正确率不到八成，当天不出新的
4. 还有空位，用最快到期的熟题补

出新的顺序：每个世界里小伙伴按表里的顺序孵，恐龙从 2 号到 10 号。前一只的事实都教过了，下一只才孵。动物乐园和恐龙岛同时开放时，每天的新事实两边轮着出。

新事实先教再问：小伙伴用十格图或分合图演示一次，马上问一道。

同一个小伙伴的题不连着出。每次夹 1~2 道看图列式。

中途退出，已答的题照常记，下次接着做。做完进完成页：今天照顾了哪几个小伙伴、谁长大了、得了几颗星。最下面一行是给家长看的：用了几分钟，做了几题，对了几题。

完成页之后可以进自由玩，默认最多 10 分钟，家长可改。

## 题型

| 题型 | 样子 |
|---|---|
| 一眼看出 | 点子卡或十格图闪 1 秒，输入几个 |
| 求得数 | 8+5=□ |
| 求加数、被减数、减数 | 8+□=13，□−5=8，13−□=8 |
| 分与合 | 分合图，一边空着 |
| 比大小 | 8+5 ○ 12，点 >、<、= 三个大按钮 |
| 数的顺序 | 数轴上空一格，或问“13 后面是几” |
| 十几的组成 | 1 个十和 4 个一是□ |
| 看图列式 | 读题配图，用大按钮拼出算式，再输入得数 |
| 口算挑战 | 每周一次，一页 20 道熟题，像学校口算纸。只和自己上次比用时，不排名。熟题够 20 道后才出现 |

## 作答与讲解

大号数字键盘：0~9、退格、确定，每个键不小于 64px。手机竖屏键盘在下；平板横屏题目在左、键盘在右。

答对：小伙伴开心一下，马上下一题。不放错误音。

答错：

1. 小伙伴说“我们一起看看”。按这道题的方法放讲解：十格图凑十、破十，或分合图
2. 他自己输入正确答案，才往下走
3. 隔 2~4 题再问这道。再错，这道题今天都带着十格图出

错法自动归类，给家长区用：

- 差 1：多数或少数了一个，多半在数手指
- 加减看反：13−5 答 18
- 进位忘了：8+5 答 3
- 退位倒着减：13−5 答 12（拿 5 减 3）
- 其他

## 星星

- 做完今日练习得 10 颗，做完口算挑战得 5 颗
- 星星不和对错挂钩。答对只有小伙伴的动画
- 自由玩不发星星
- 每满 100 颗，岛上自动多一样装饰，顺序固定，第一版 8 样

不做连续打卡、排行榜、倒计时。漏一天不罚，只是小伙伴犯困。

## 首次使用

1. 家长登录，填孩子的称呼
2. 家长录音。先录“必需”那一组就能开始，其余以后补
3. 孩子做 30 秒按键热身
4. 摸底，约 5 分钟、30 题左右：一眼看出，恐龙岛每只抽 2 道，凑十，再抽几道 20 以内。一类题错到 3 道就停这一类，不让他一直错
5. 答对且熟练的放格子 4，答对但慢的放格子 1，答错的从头来。一只小伙伴抽到的题全部熟练，它没考到的事实放格子 3，之后靠复习验证；其余没考到的从头来
6. 进岛。八成事实已到格子 3 的小伙伴直接是长大的样子，再孵出第一只新的

## 声音

题目读法、讲解、鼓励都用家长的录音。第一版约 90 条，每条 1~10 秒：

- 必需（约 40 条）：0~20 每个数；加、减、等于、几、比、大、小、分成、和、个十、个一；每种题型的提示语
- 讲解：凑十、破十、想加算减、分合图的几段固定说法
- 鼓励：答对、答错后鼓励、长大、进化，每种 2~3 条，轮着放
- 名字：孩子的称呼、三个世界、22 个小伙伴

算式靠拼接播放：“8”“加”“5”“等于几”。题型提示语只在当天这种题第一次出现时放，算式默认不读，他点喇叭才读。

录音页按组列出要录的句子和进度。每条能试听、重录。录完在手机上自动去掉首尾静音、统一音量，转单声道 16kHz WAV 上传。

微信内置浏览器的麦克风权限不稳定，录音页提示用手机自带浏览器打开。没录的句子先显示文字，并尝试用浏览器朗读。

播放用 Web Audio，在第一次点按时解锁声音，绕开微信的自动播放限制。录音下载后存在设备上，断网也能放。

## 画面

小伙伴的画在开发时用图片模型生成，提交进仓库。孩子的设备不访问生图接口。

- 每个世界一种蛋，每个小伙伴三张：小时候、长大、进化。加 8 样装饰和 3 张世界背景，第一版约 80 张
- 先用「8 号恐龙」出几种画风给家长挑，定了再批量生成
- 生成长大、进化时，把前一阶段的图作为参考图传进去，保证是同一只
- 直接要透明背景，裁掉空边，压成 512px 的 WebP
- 开心、犯困、跳一跳用 CSS 动画做，不另外出图
- 图没到位之前，用代码画的简单占位图

接口地址、key、模型名放在本机不提交的 `.env.local` 里：`IMAGE_API_BASE`、`IMAGE_API_KEY`、`IMAGE_MODEL`。换模型只改 `IMAGE_MODEL`。

- `npm run art models`：列出可用模型
- `npm run art styles`：用「8 号霸王龙」出三种画风 × 三个阶段，拼成 `art-raw/styles/sheet.png`
- `npm run art use <画风>`：把选中画风的三张图放进游戏

## 家长区

首页角落一个小锁。点开要答一道乘法题（例如 7×8），一年级孩子进不去。

- 今天和最近 7 天：练了几天、几分钟、几题、正确率
- 加减法表：每格一个事实，按格子上色，一眼看出哪片还弱
- 对但慢最多的 10 道，错得最多的 10 道
- 错法分布
- 录音页
- 设置：孩子称呼、每天题数、自由玩时长、暂停出新题

## 技术形状

前端：

- Vue 3 `<script setup>` + TypeScript + Vite。构建目标 es2020 + safari14 + chrome87，兼容微信内置浏览器
- 不用 UI 组件库。图形用 SVG，动画用 CSS
- 纯逻辑放在 `src/lib`，写单元测试：事实表、格子与排期、熟练线、组卷、错法归类、成长阶段、事件合并
- 离线优先。每次作答写成一条事件，先存 IndexedDB，联网后上传
- 掌握情况不单独存，全部由事件按时间重算。两台设备的事件合并后按（时间、编号）排序重算，结果一致，不会冲突。一年约一万条事件，重算很快

后端：

- 新的 Go module，模块名 `mathbuddies`。Go 1.22，SQLite 用 `modernc.org/sqlite`，启用 WAL 和外键
- 只负责登录、存取事件、设置、录音，并提供前端静态文件。出题和记忆计算都在前端
- 前端构建产物用 `embed` 打进同一个二进制，部署只传一个文件
- 监听 `127.0.0.1:8091`。攒星星占 `8090`，个人实验室占 `8080`

## 登录

全家一个密码，家长设置。手机和平板各登录一次，之后保持登录。孩子不输密码。

- 密码用 bcrypt 保存。首次启动读 `MB_PASSWORD` 写入哈希，确认能登录后从 systemd unit 里删掉，与攒星星做法一致
- 会话令牌是 32 字节随机数，服务端只存其 SHA-256。cookie 为 HttpOnly、Secure、SameSite=Lax，180 天，使用时顺延
- 退出登录吊销会话。登录接口按 IP 限流，每小时 10 次失败

## 接口

| 方法与路径 | 作用 |
|---|---|
| `POST /api/login`、`POST /api/logout` | 登录、退出 |
| `GET /api/events?after=<序号>` | 拉取某序号之后的事件，分页 |
| `POST /api/events` | 批量上传事件。按客户端生成的 UUID 去重，重传无害 |
| `GET /api/settings`、`PUT /api/settings` | 读写设置，后写的覆盖先写的 |
| `GET /api/clips` | 录音清单：句子编号、内容哈希、更新时间 |
| `GET /api/clips/{id}`、`PUT /api/clips/{id}` | 下载、上传一条录音 |

除登录外都要会话，未登录返回 401。写接口只收 JSON 或 `audio/wav`，并校验 `Origin`。单条录音不超过 1MB。

## 数据

- `family`：一行，密码哈希
- `session`：令牌哈希、创建时间、最后使用时间、是否吊销
- `child`：一行，称呼
- `event`：服务端序号（自增）、客户端 UUID（唯一）、孩子、设备编号、种类、发生时间、JSON 内容
- `setting`：键、值、更新时间
- `clip`：句子编号（主键）、WAV 内容、内容哈希、更新时间

事件种类：`answer`（事实、题型、答案、对错、用时、是否听了读题）、`session_start`、`session_end`、`placement`、`baseline`。星星、格子、成长阶段都由事件算出，不存。

录音直接存在 SQLite 里，全部只有几 MB。备份一个文件就带走全部数据。

## 测试

前端纯函数用 vitest，用固定的假时钟：

- 新事实教完答对，进格子 1
- 格子 2 以上答对但不熟练，不进格
- 同一天答对两次，只进一格
- 同一天连错几次，只减半一次
- 没到期答对不进格；答错照样减半
- 答错减半，本次练习里隔 2~4 题再出现
- 答错后再答对：格子 0 进到 1，其余不动
- 两台设备的事件交错合并，与按时间单台做出的结果一致；同一事件重复只算一次
- 八成事实到格子 3 时变为长大；之后格子回落，阶段不降
- 最近两次正确率不到八成时，不出新事实
- 同一小伙伴的题不相邻
- 错法归类：13−5 答 12 是退位倒着减，8+5 答 3 是进位忘了，答 12 或 14 是差 1
